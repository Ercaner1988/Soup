# readme-tool data (Soup translations, 2026-10)

Working data for a README / multilingual repository-description tool, collected while translating
Soup's README. Not part of Soup. Append-only.

- `decisions.md` — maintainer rules and what the review rounds showed
- `findings.jsonl` — every LLM review finding (round, model, language, line, quote, fix)
- `reviews/` — the review reports as text
- `prompts/` — translator, reviewer and fixer prompts as used
- `workflows/` — the review workflow scripts
- `readme-tool-prompt-report.md` — first design/prompt report for the tool
- `routine-prompt.md` — the scheduled routine's prompt
